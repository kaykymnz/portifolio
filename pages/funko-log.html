Funko Log

Sistema leve para cadastro, edição e exibição de produtos Funko POP, desenvolvido como pratica de integracao entre front-end, PHP e MySQL.

Tipo Projeto de pratica
Stack PHP, MySQL, Bootstrap
Status Concluído

Sobre o projeto

Funko Log e uma aplicação CRUD para gerenciar e exibir produtos Funko POP. O projeto foi construído para treinar persistência de dados, telas de admnistração e exibição de catálogo em uma solução simples e funcional.

Objetivo

Criar uma aplicação web que permita cadastrar, listar, editar e excluir produtos em um banco MySQL, mantendo um fluxo direto para pequenas coleções ou lojas de nicho.

Funcionalidades principais

  • Catálogo visual de Funkos cadastrados.
  • Área administrativa para novos produtos.
  • Edição de informações de itens existentes.
  • Exclusão de produtos do catálogo.
  • Estrutura pensada para uso local ou hospedagem simples.

Arquitetura técnica

A aplicação segue uma estrutura de três camadas: apresentação em HTML, CSS e JavaScript, logica de negócio com PHP e persistência em MySQL gerenciada via phpMyAdmin.
