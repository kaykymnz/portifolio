Funko Log

Sistema leve para cadastro, edicao e exibicao de produtos Funko POP, desenvolvido como pratica de integracao entre front-end, PHP e MySQL.

Tipo Projeto de pratica
Stack PHP, MySQL, Bootstrap
Status Concluido

Sobre o projeto

Funko Log e uma aplicacao CRUD para gerenciar e exibir produtos Funko POP. O projeto foi construido para treinar persistencia de dados, telas de administracao e exibicao de catalogo em uma solucao simples e funcional.

Objetivo

Criar uma aplicacao web que permita cadastrar, listar, editar e excluir produtos em um banco MySQL, mantendo um fluxo direto para pequenas colecoes ou lojas de nicho.

Funcionalidades principais

  • Catalogo visual de Funkos cadastrados.
  • Area administrativa para novos produtos.
  • Edicao de informacoes de itens existentes.
  • Exclusao de produtos do catalogo.
  • Estrutura pensada para uso local ou hospedagem simples.

Arquitetura tecnica

A aplicacao segue uma estrutura de tres camadas: apresentacao em HTML, CSS e JavaScript, logica de negocio com PHP e persistencia em MySQL gerenciada via phpMyAdmin.
