Sobre o projeto

O Apolo Veículos e um sistema web para gerenciamento de negociações de automóveis. A aplicação simula a rotina de uma revendedora, conectando clientes interessados, vendedores responsáveis e administradores que acompanham o estoque.

Objetivo

Desenvolver uma aplicação completa para controlar o processo comercial de uma loja de veículos, reduzindo desorganização em negociações e facilitando o acompanhamento do status de cada atendimento.

Funcionalidades principais

  • visualização de veículos disponíveis pelo cliente.
  • Formulário para registrar interesse em um automovel.
  • Área de vendedores para acompanhar negociações.
  • Dashboard administrativo com controle de estoque.
  • Atualização de status e cancelamento de negociações.
